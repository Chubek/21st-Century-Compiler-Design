2 Zephyr compilation strategy

 The compiler writer chooses an intermediate

representation for the front end to target.
Freedom to choose intermediate representations
is an important element of compiler research;
for example, the recent trend toward typed
intermediate languages could not have been
predicted ve years ago. The Zephyr tools
enable freedom of intermediate representations
by integrating with any tree-like
representation. Zephyr includes an Abstract
Syntax Description Language (ASDL) for
de ning tree-like representations. The ASDL
generator, asdlGen, helps compiler writers
build and interconnect tools using tree-like
representations.
 The Zephyr infrastructure gives the compiler
writer a guide for connecting the intermediate
representation to the optimizer and for making
a complete back end.

The Zephyr compilation strategy is to assemble compilers from parts.
 The compiler writer supplies the front end.
This front end can use any of the wide variety
of lexer generators, parser generators, and
attribute-grammar evaluators that are
commonly used to build front ends, and it can
be written in any programming language.
 The Zephyr toolset supplies several parts:
{ A machine-independent optimizer, VPO,
{ Back-end components for use in the
machine-dependent parts of the compiler,
and
{ Glue for connecting the compiler
